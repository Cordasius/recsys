## Запуск

Для запуска установите окружение, скачайте зависимости из requirements.txt, далее можно прогонять ноутбук с этим окружением, скачивание датасета там уже есть в ячейках. 


## Содержимое

- `experiments.ipynb` — полноценный ноутбук со всеми действиями
- `models/` — модели
- `data_utils.py` - работа с данными 
- `evaluation.py` — метрики
- `requirements.txt` — окружение
